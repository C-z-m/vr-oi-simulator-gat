# vr-oi-simulator-gat

**VR OI 参赛模拟器 —— Grand Assault Teacher! (GAT Beta)**

一个纯前端的网页游戏：用 Three.js 搭建 3D 考场，以第一人称视角参加 4 小时模拟 OI 竞赛。
但如果 200 杀推开了考场尽头的那扇白光门，你将进入第二幕——**一座完整的开放世界赛博都市**。

## 运行

直接用浏览器打开 `index.html` 即可，无需构建、无本地依赖。唯一的外部要求是能访问
cdn.jsdelivr.net 加载 Three.js；加载失败时页面会给出明确提示。

## 第二幕：GAT 城市模式（Grand Assault Teacher!）

当你打满 200 个保安，走廊尽头的门被白光灌满，走进去后，迎接你的不是结局，而是一座巨大的 4x4 开放式赛博街区。

### 核心系统

- **无缝城市路网**：程序化生成的棋盘街道，包含高耸入云的摩天大楼、精致的便利店、随机停放的 30 辆汽车，以及被高墙封闭的边界。
- **通缉系统**：你的头顶会亮起通缉星级。杀敌和破坏会增加星级（1~5 星）。
- **警察兵种分级**：
  - **1~2 星**：普通警察（深蓝制服，手枪）。
  - **3 星**：加入狙击手（绿色制服，带红色激光瞄准，远距离一枪致命）。
  - **4 星**：加入特警（黑头盔红面罩，防弹衣需 3 枪致死）。
  - **5 星**：军队介入（绿头盔，射速极快）。
- **A* 智能寻路**：所有警察都接入了 A* 寻路算法。他们不再被车卡住，会像特种兵一样绕过掩体，甚至顺着墙根包抄躲在便利店里的你。移动中也能精准开枪。
- **载具驾驶与爆炸**：
  - 按 E 上车，W/S 控制油门倒车，A/D 转向。
  - 踩死油门可以直接碾压碾碎警察和路人。
  - 车辆可以被打爆（4 枪）。爆炸会产生 6 米范围的 AOE 伤害，且会引发周边车辆的连环殉爆。
- **46 届都市传说**：城市里藏有前代考生的痕迹。
  - 便利店内的监控屏幕。
  - 全图最偏僻角落大楼上的粉色涂鸦。
  - 找齐线索后，会触发隐藏的「档案解密」结局。

## 考场操作

| 操作 | 行为 |
|---|---|
| `W` `A` `S` `D` | 移动 |
| `Shift` | 疾走 |
| `空格` | 跳跃 |
| 鼠标移动 | 转动视角（FPS 视角锁定） |
| `E` / `鼠标左键` | 交互（电脑 · 草稿纸 · 水杯 · 出门 · **上下车**） |
| `鼠标左键` | 出拳 / **全自动射击**（持枪时） |
| `R` / `Q` | 换弹 / 收枪拔枪 |
| `F` | 干扰同学 |
| `H` | 举手呼叫监考 |
| `Esc` | 释放鼠标 / 打开设置 |

弹窗操作：**视线停留 1 秒**自动确认，也可直接左键点击。

## 手枪与武器

打倒监考老师后，讲台底下会掉出一把旧手枪；若去了洗手间，也能在检修口里摸到枪。

- **全自动模式**：按住左键即可倾泻火力（射速 10发/秒），不过散布会让你在远距离打空。
- **弹匣 12 发，备弹上限 72**。桌子和墙会挡住子弹，但汽车挡不住。
- **爆炸物**：对着汽车连开 4 枪，汽车的 6 米 AOE 爆炸会无差别炸死周围的所有人（包括你自己，记得拉开距离）。

## 隐藏结局

在考场打满 200 杀，门外会亮起白光。走进去，你将进入第二幕。而在城市中：
- 如果被 5 星军队乱枪打死，GAT 行动终结。
- 如果顶着通缉逃到城市最北边，进入深邃的「出城隧道」，按 E 离开，你将触发真正的城市结局。
- 如果你找齐了全部 2 个「46 届痕迹」，并且身边没有警察追杀你，屏幕中央会弹出一个压抑的真相面板，告诉你那扇门、这座城市的终极秘密。

## 存档

存档系统已全面升级。现在的 `localStorage` 会记录：
- 你的精确坐标、视角、当前区域（考场 / 街道）。
- 你的血量、弹药、通缉星级、击杀数。
- 线索收集进度。
**如果在城市里刷新，你会在城市的安全点醒来；如果被随机刷新的车卡住，系统会自动将你转移到安全位置。**

## 隐藏特性 / 开发者提示

- **空格穿模**：由于底层的空中判定未锁定物理轴，你可以在车头前按空格起跳，直接穿进车模型里，用来把车当掩体。
- **幽灵车墙**：如果发现汽车开走后留下了空气墙，那是因为你没更新 `driving.js` 里的动态碰撞解除逻辑。
- **F12 传送**：`state.pos.set(x, 1.65, z)` 可以直接把你扔到地图的任何角落。
- **快速升星**：`state.cityMode.wantedLevel = 5; document.getElementById('wantedHud').textContent = '★★★★★';`
